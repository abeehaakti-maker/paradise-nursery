# Paradise Nursery

Paradise Nursery is an online plant shop built with React and Redux Toolkit. Visitors can browse houseplants by category, add plants to a shopping cart, change quantities, remove items and see the total cost.

## Features
- Landing page with the company name, background image and a Get Started button
- About Us section describing the company
- Product listing with 3 categories and 6 plants each
- Add to Cart buttons that disable once a plant is added
- Navbar with Home, Plants and a cart icon showing the item count
- Shopping cart page with quantities, item totals, a total amount, delete, Checkout (Coming Soon) and Continue Shopping

## Run locally
```
npm install
npm run dev
```
